La huella digital de un documento: funciones hash

🔎 Un resumen imposible de falsificar

Una función hash (o función resumen) coge un documento de cualquier tamaño —una frase o un libro entero— y produce un código de longitud fija, algo así como su huella digital. Los algoritmos reales, como SHA-256, producen siempre un código de 64 caracteres hexadecimales.

Hash simplificado con fines educativos (no es SHA-256, el algoritmo real que usan los certificados), pero muestra las mismas propiedades.

Las tres propiedades que la hacen útil

  • 🔁 Determinista: el mismo documento produce siempre el mismo hash. Es la propiedad que acabas de comprobar al comparar dos textos idénticos.
  • 💥 Efecto avalancha: cambiar una sola letra, una coma o un espacio produce un hash completamente distinto. Por eso sirve para detectar cualquier modificación, por pequeña que sea.
  • 🚫 No reversible: a partir del hash es imposible reconstruir el documento original. El hash no es una versión «comprimida» del documento, solo sirve para comparar.

¿Para qué se usa?

El hash es la pieza que hacía falta para completar la firma digital: en vez de cifrar (con la clave privada) el documento entero —algo lento si el documento es grande—, se cifra únicamente su hash, mucho más corto. Es exactamente lo que verás en el próximo módulo.

💡 Consejo: Muchas páginas de descargas publican, junto al archivo, su hash SHA-256. Si al calcular el hash del archivo descargado no coincide con el publicado, el archivo se ha corrompido o ha sido manipulado.
