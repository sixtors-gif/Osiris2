Buscar y reemplazar

Buscar: la barra rápida

  1. Pulsa Ctrl+F para abrir la barra de búsqueda (aparece abajo, o flotante, según la aplicación).
  2. Escribe la palabra o frase que buscas.
  3. Pulsa Intro para saltar a la siguiente coincidencia, y sigue pulsando para ir avanzando por el documento.
  4. Pulsa Esc para cerrar la barra de búsqueda.

Funciona igual para encontrar una palabra en un informe de Writer, un dato en una hoja de Calc o un texto dentro de una presentación de Impress.

Buscar y reemplazar: cambiar muchas veces de golpe

Si necesitas sustituir una palabra por otra (por ejemplo, corregir un nombre mal escrito en todo el documento), usa la ventana completa.

  1. Pulsa Ctrl+H para abrir Buscar y reemplazar.
  2. Escribe en Buscar lo que quieres localizar, y en Reemplazar por, el texto nuevo.
  3. Pulsa Reemplazar todo para cambiarlo en todo el documento de una vez, o Buscar siguiente y Reemplazar para ir uno a uno.

Opciones útiles

  • 🔠 Coincidir mayúsculas y minúsculas: distingue «Catering» de «catering». Actívala si el uso de mayúsculas importa.
  • 🔤 Solo palabras completas: evita que, al buscar «sal», también encuentre «salir» o «ensalada».
  • 🧩 Expresiones regulares: una opción avanzada para búsquedas con patrones (por ejemplo, cualquier número de teléfono). No hace falta para el uso diario.
⚠️ Error típico: Antes de pulsar Reemplazar todo, revisa bien lo que has escrito en ambos campos: un espacio de más o una palabra mal escrita puede cambiar cosas que no querías.
