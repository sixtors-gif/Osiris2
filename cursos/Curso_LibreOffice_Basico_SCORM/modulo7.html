Ortografía, idioma y autocorrección

La revisión ortográfica en tiempo real

Mientras escribes, una línea roja ondulada bajo una palabra indica que LibreOffice no la reconoce en el diccionario del idioma activo. Haz clic derecho sobre ella para ver sugerencias, o para añadirla al diccionario personalizado si es una palabra correcta (un nombre propio, un término técnico…).

  1. Clic derecho sobre la palabra subrayada.
  2. Elige una de las sugerencias para corregirla, o Añadir al diccionario si está bien escrita.
  3. Para revisar todo el documento de una vez, pulsa F7 (Ortografía y gramática).
💡 Consejo: Si una palabra correcta se subraya siempre (por ejemplo, el nombre de tu centro o un término de cocina), añádela al diccionario una sola vez y no volverá a marcarse.

El idioma del documento

La corrección se hace según el idioma asignado al texto (puede haber varios idiomas en el mismo documento). Se cambia en Herramientas → Idioma, o en la barra de estado, donde suele verse el idioma actual.

⚠️ Error típico: Si de repente todo el documento se subraya en rojo, puede que el idioma esté mal asignado, o que falte instalar el diccionario de ese idioma (Herramientas → Idioma → Más diccionarios).

Autocorrección: cambios automáticos mientras escribes

LibreOffice corrige o transforma ciertas cosas automáticamente mientras tecleas: pone en mayúscula la primera letra de una frase, convierte las comillas rectas en tipográficas («así»), o sustituye errores de escritura habituales.

  1. Ve a Herramientas → Autocorrección → Opciones de Autocorrección…
  2. En la pestaña Reemplazar puedes añadir tus propios reemplazos automáticos (por ejemplo, que «tfno» se convierta siempre en «teléfono»).
  3. En Opciones activas o desactivas comportamientos como «Mayúscula al inicio de frase» o «Corregir DOs mayúsculas INiciales».
Microsoft Office En Word/Excel/PowerPoint esta misma función se llama «Autocorrección» y se configura en Archivo → Opciones → Revisión.

¿Para qué sirve la Autocorrección?

Para cambiar automáticamente ciertos textos mientras escribes (mayúsculas, comillas, erratas frecuentes)
Para traducir el documento a otro idioma
