Formatos de archivo: ODF, Microsoft Office y PDF

ODF: el formato nativo de LibreOffice

ODF (OpenDocument Format) es el formato abierto y estándar en el que LibreOffice guarda por defecto. Cada aplicación tiene el suyo:

AplicaciónFormato nativo (ODF)Formato de Microsoft equivalente
Writer.odt.docx
Calc.ods.xlsx
Impress.odp.pptx
Draw.odg(sin equivalente exacto)
Base.odb.accdb

Compatibilidad con Microsoft Office

LibreOffice también puede abrir y guardar en los formatos de Microsoft Office (.docx, .xlsx, .pptx). Al hacerlo, verás un aviso como este:

Usar formato de Word 2007-365✕
MensajeHa elegido guardar el documento en un formato distinto del formato ODF predeterminado.
¿Desea usar el formato Word 2007-365?
Usar formato Word 2007-365Usar formato ODF
⚠️ Error típico: Al cambiar de formato puede perderse algún detalle de diseño muy específico de un programa (una fuente rara, un efecto avanzado). Si vas a compartir el archivo con quien usa Microsoft Office, ábrelo después de guardar y revísalo.

Quiero que se vea igual en cualquier dispositivo y que no se pueda modificar.pdf

Un archivo, una versión activa

Cuando guardas como .docx, el archivo abierto pasa a ser el .docx. Si sigues trabajando y pulsas Guardar, se guarda en ese .docx; el .odt original no se actualiza solo. Si necesitas las dos versiones al día, haz «Guardar como» de nuevo al terminar.

💡 Consejo: Puedes cambiar el formato en el que LibreOffice guarda por defecto en Herramientas → Opciones → Cargar/Guardar → General, muy útil si trabajas casi siempre con archivos de Microsoft Office.
