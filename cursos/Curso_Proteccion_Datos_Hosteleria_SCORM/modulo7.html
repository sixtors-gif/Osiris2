Marketing, fidelización y comunicaciones comerciales

📧 ¿Cuándo se puede enviar publicidad?

Para enviar ofertas, newsletters o invitaciones a eventos necesitas una base legal: normalmente el consentimiento explícito del cliente, o su condición de cliente habitual para ofrecerle productos similares (siempre con la opción fácil de darse de baja).

El consentimiento tiene que ser una decisión activa del cliente, nunca algo que venga ya aceptado.

  • 🚫 No cedas datos a otras empresas, agencias o "partners" sin el permiso explícito del cliente para ese fin concreto.
  • ✋ Baja fácil: darse de baja de la newsletter o el club de fidelización debe ser tan sencillo como apuntarse, con un enlace visible en cada comunicación.
  • 📝 Encuestas de satisfacción: están bien vistas si son para mejorar el servicio; evita usarlas como excusa para captar datos con otros fines sin decirlo.
  • 🎂 Programas de fidelización (puntos, descuentos por cumpleaños): explica claramente qué datos usan y para qué al darse de alta.
