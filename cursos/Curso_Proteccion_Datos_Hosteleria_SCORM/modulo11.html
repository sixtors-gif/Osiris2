Datos del personal: empleados y nóminas

🗂️ Nóminas y contratos

Las nóminas, contratos y datos bancarios del personal solo deben ser accesibles para dirección y administración/RRHH, nunca visibles para cualquier compañero o de forma pública en un tablón.

🖐️
Control horarioSi se usa huella o reconocimiento facial para fichar, es un dato biométrico especialmente protegido: debe existir una alternativa (tarjeta, código) para quien no quiera usarlo.
📹
Cámaras en el trabajoPermitidas en zonas de atención al público; prohibidas en vestuarios y zonas de descanso del personal, como viste en el módulo 6.
📱
Dispositivos de empresaEl móvil, tablet o PMS de trabajo son para uso profesional. Evita hacer fotos con datos de clientes o compañeros para uso personal.
🤐
Confidencialidad internaLos datos de un compañero (nómina, bajas médicas, situación personal) no se comentan con el resto del equipo.
⚠️ Cuidado con la biometría: huella dactilar o reconocimiento facial para el control horario están permitidos, pero requieren una base legal adecuada y nunca pueden ser la única opción obligatoria para todo el personal.
  • 📸 Fotos del equipo para la web o redes sociales del establecimiento: necesitan el consentimiento de cada persona trabajadora que aparece.
  • 🏥 Bajas médicas: el motivo médico concreto de una baja es un dato de salud; en administración basta con gestionar el justificante, sin necesidad de difundir el diagnóstico.
  • 🔐 Acceso por rol: cada persona debería acceder solo a los datos que necesita para su puesto, igual que viste con los datos de clientes.

🧩 Ejercicio práctico: El nuevo fichaje

El establecimiento instala un sistema de fichaje por huella dactilar y lo hace obligatorio para todo el personal, sin alternativa. ¿Es correcto?
