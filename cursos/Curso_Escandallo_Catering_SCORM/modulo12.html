Revisión, errores y buenas prácticas

1. Revisa tus fórmulas

  1. Activa Ver → Mostrar fórmula (Ctrl+`) para ver todas las fórmulas a la vez y comparar filas.
  2. Selecciona una celda con resultado y usa Herramientas → Detective → Rastrear precedentes: dibuja flechas hacia las celdas de las que depende.
  3. Comprueba que las fórmulas de una misma columna son iguales (solo cambia el número de fila).

2. Pruébalo con casos límite

3. Los errores más frecuentes

ErrorQué significaCómo se arregla
#¡DIV/0!Estás dividiendo entre 0 o entre una celda vacíaRevisa el divisor; usa SI para controlar el caso
#¡REF!La fórmula apunta a una celda u hoja que ya no existeVuelve a hacer clic en la celda correcta; no borres hojas de las que depende algo
#NOMBRE?Función o nombre mal escrito (SUMAA)Corrige el nombre de la función
#¡VALOR!Operas con texto donde hace falta un númeroComprueba que la celda es un número, no un texto
###La columna es demasiado estrechaEnsancha la columna (doble clic en el borde)

4. Presentación clara

  • 🎨 Colores con sentido: por ejemplo, un fondo suave para los datos que se teclean y otro para las fórmulas.
  • 🧊 Ver → Inmovilizar filas y columnas para que los títulos no desaparezcan al bajar.
  • 🖨️ Formato → Página → ajusta la hoja Totales a una página de ancho para imprimirla.
  • 📅 Guarda una copia con la fecha en el nombre (Escandallo_2025-01-10.ods) antes de hacer cambios grandes.

5. Evita errores de teclear

  1. Validez de datos: selecciona B3 en una ficha → Datos → Validez… → permite «Número entero» mayor que 0. Así nadie pone 0 raciones.
  2. Selecciona C3 en Totales → Validez → «Decimal» entre 0 y 1 para el % de beneficio.
  3. Proteger la hoja: desbloquea las celdas donde se teclean datos (Ctrl+1 → pestaña Protección → quitar «Protegida») y luego Herramientas → Proteger hoja…. Así nadie borra una fórmula por accidente.
💡 Consejo: Para que la protección no moleste, deja sin proteger solo las celdas de entrada: nombre, raciones, ingredientes, precios, comensales y porcentajes.
