Ofimática: LibreOffice

Si vienes de Word y Excel, LibreOffice te resultará muy familiar. Abre y guarda también los formatos de Microsoft Office (.docx, .xlsx, .pptx), así que puedes intercambiar documentos con quien use Windows sin problemas. Si has hecho el curso de LibreOffice de esta misma serie, ya sabes manejarlo: es exactamente el mismo programa.

¿Y si el programa que uso en Windows no existe en Ubuntu?

Ubuntu ofrece miles de aplicaciones. Muchas son las mismas que en Windows y están disponibles también para Ubuntu: por ejemplo Firefox, Chrome, Spotify, Telegram, Discord, Slack, Steam, OBS Studio, Blender o Visual Studio Code. Otras tienen una alternativa libre equivalente. Antes de dar nada por perdido: búscalo en el App Center y, si no aparece, comprueba si tiene versión web.
