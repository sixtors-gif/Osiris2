Versiones, sabores y requisitos

🗓️ Cómo se numeran las versiones

Los números de Ubuntu son una fecha: año.mes de lanzamiento. Por eso 26.04 significa abril de 2026. Cada versión tiene también un nombre en clave formado por un adjetivo y un animal: la 26.04 es «Resolute Raccoon» (mapache resuelto). Se publicó el 23 de abril de 2026, y la revisión 26.04.1 es la que hoy ofrece la web de descarga.

LTS frente a versiones intermedias

LTS (soporte a largo plazo)Intermedia
Cuándo saleCada dos años, en abril (como la 24.04 y la 26.04)Cada seis meses (como la 25.10)
Soporte5 años de actualizaciones de seguridad gratuitas (la 26.04 hasta abril de 2031)Mucho más corto: hay que actualizar a la siguiente
Para quiénLa mayoría de personas y centros: estable y duraderaQuien quiere lo último cada seis meses
Ubuntu Pro: es una suscripción de Canonical que amplía el soporte de seguridad hasta 15 años en total. Es gratuita para uso personal en hasta 5 equipos. Para empezar no la necesitas.

Para el aula y para tu casa, la recomendación general es usar siempre una versión LTS: cambias de versión solo cada dos años y tienes cinco de tranquilidad.

💡 Actualizar de una LTS a otra: Ubuntu solo permite hacerlo de forma secuencial (de una LTS a la siguiente). Si usas la 24.04 LTS, podrás subir a la 26.04 LTS; si usas una más antigua, primero hay que pasar por la 24.04. Lo verás en el módulo de actualizaciones.

Los sabores oficiales de Ubuntu

Además de Ubuntu «a secas» existen sabores oficiales: mismo sistema base y mismo repositorio de software, pero con otro escritorio o con un objetivo concreto.

SaborPara qué
KubuntuEscritorio KDE Plasma, muy personalizable
Xubuntu y LubuntuEscritorios ligeros: ideales para ordenadores antiguos o con poca memoria (desde 2 GB de RAM)
Ubuntu Budgie, Ubuntu Cinnamon, Ubuntu UnityOtros escritorios, con aspecto más clásico o diferente
Ubuntu StudioCreación de audio, vídeo y gráficos
EdubuntuEducación
Ubuntu KylinVersión para usuarios de habla china

ComponenteMínimo para una experiencia cómoda

InternetRecomendable para actualizaciones y programas, pero no obligatorio para la instalación inicial

🧪 ¿Cumple mi ordenador los requisitos?

Escribe los datos de tu equipo (los encuentras en la configuración de Windows, en «Acerca de») y comprueba si encaja con Ubuntu Desktop 26.04 LTS.

Descargar Ubuntu

La descarga oficial es siempre desde ubuntu.com/download/desktop. La imagen (archivo ISO) pesa unos 5,9 GB para ordenadores Intel/AMD de 64 bits y 3,9 GB para ARM de 64 bits.

Captura realPágina oficial de descarga de Ubuntu Desktop. Fuente: ubuntu.com/download/desktop (6 de octubre de 2026). El aspecto puede cambiar con el tiempo.

⚠️ Descarga Ubuntu solo desde la web oficial. Los sitios que ofrecen «versiones especiales» o «con programas incluidos» pueden esconder software dañino.
