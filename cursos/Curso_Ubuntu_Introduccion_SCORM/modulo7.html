Ventanas, espacios de trabajo y atajos

🪟 Trabajar con varias ventanas

Cuando tienes abiertos un navegador, un documento y un correo, saber moverte entre ventanas te ahorra mucho tiempo. Ubuntu ofrece varias formas; elige la que te resulte más cómoda.

Con el ratón

  • 🖱️ Arrastra la barra de título para mover la ventana. Arrastrarla hasta el borde izquierdo o derecho la ajusta a media pantalla.
  • ➖ Los botones de la barra de título minimizan, maximizan o cierran. En Ubuntu, el botón de cerrar es naranja.
  • 🧲 Si arrastras una ventana hasta el borde superior, se maximiza.

Con el teclado: los atajos esenciales

AtajoQué hace
SuperAbre las Actividades (buscar y ver ventanas)
Alt + TabCambia entre aplicaciones abiertas (mantén Alt y pulsa Tab varias veces)
Super + Flecha izquierda / Super + Flecha derechaAjusta la ventana a la mitad izquierda o derecha
Super + Flecha arriba / Super + Flecha abajoMaximiza / restaura la ventana
Alt + F4Cierra la ventana actual
Super + DMuestra el escritorio (oculta todas las ventanas)
Super + LBloquea la pantalla
Ctrl + Alt + TAbre una terminal
ImprPantAbre la herramienta de captura de pantalla (también para grabar la pantalla)
Ctrl + C Ctrl + X Ctrl + V Ctrl + ZCopiar, cortar, pegar y deshacer: igual que en Windows
💡 Grabar la pantalla: pulsa ImprPant y cambia a «Grabar pantalla», o usa directamente Ctrl + Alt + Mayús + R. Un indicador rojo en la barra superior te dice que estás grabando; púlsalo para parar. El vídeo se guarda en Vídeos/Screencasts, dentro de tu carpeta personal.

Espacios de trabajo: varios escritorios en uno

Un espacio de trabajo es un escritorio virtual. Puedes tener, por ejemplo, el navegador y el correo en uno, y los documentos de clase en otro, sin que se mezclen las ventanas. Se ven y gestionan desde las Actividades: arrastra una ventana a otro espacio de trabajo o cambia entre ellos con [[Ctrl+Alt+Flecha arriba]] y [[Ctrl+Alt+Flecha abajo]].

Si vienes de Windows Los espacios de trabajo se parecen a los «escritorios virtuales» de Windows (Win + Tab).
🎯 Idea clave: aprender cinco atajos —Super, Alt+Tab, Super+flechas, Alt+F4, Super+L— cambia tu forma de trabajar.
