Archivos, carpetas y rutas

Un archivo (o fichero) es un documento, foto, canción o programa guardado. Las carpetas sirven para agruparlos, y pueden contener otras carpetas. El camino hasta un archivo se llama ruta.

Una estructura ordenada y la ruta para llegar a un archivo.

La extensión: el «apellido» del archivo

Las letras después del punto indican el tipo de archivo y con qué programa se abre.

ExtensiónTipoSe abre con…
.odt / .docxDocumento de textoLibreOffice Writer, Word
.ods / .xlsxHoja de cálculoLibreOffice Calc, Excel
.pdfDocumento para leer o imprimirNavegador, lector de PDF
.jpg / .pngImagenVisor de fotos
.mp3AudioReproductor de música
.mp4VídeoReproductor de vídeo
.zipArchivo comprimidoEl propio sistema operativo
.exePrograma de Windows⚠️ Solo si viene de una fuente de confianza

Buenas costumbres

  • 🗂️ Usa nombres claros: tarea_fracciones_v2.odt mejor que documento1.odt.
  • 🗂️ Evita espacios raros, tildes y símbolos en los nombres si vas a compartir archivos: usa guiones bajos.
  • 🗂️ Crea una carpeta por asignatura o proyecto.
  • 🗂️ Vacía de vez en cuando la carpeta de Descargas.
  • 🗂️ Lo que va a la Papelera aún se puede recuperar; al vaciarla, ya no.
Doble extensión = alarma. Un archivo llamado notas.pdf.exe parece un PDF, pero es un programa. No lo abras.
