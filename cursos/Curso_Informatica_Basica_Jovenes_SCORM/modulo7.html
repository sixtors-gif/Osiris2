🪟Módulo 7: El sistema operativo

El programa principal: arranca el equipo y organiza todo lo demás.

Informática básica · Módulo 7 de 12

El director de orquesta

El sistema operativo (SO) es el primer programa que se carga al encender el equipo. Se encarga de:

  • 🎼 Gestionar el hardware: memoria, procesador, discos, periféricos.
  • 🎼 Ofrecer una interfaz (ventanas, iconos, menús) para que puedas usar el equipo.
  • 🎼 Organizar los archivos y carpetas.
  • 🎼 Gestionar usuarios y permisos, y proteger el sistema con actualizaciones.
